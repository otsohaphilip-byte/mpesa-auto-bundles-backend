# M-Pesa Auto Bundles Android App

Native Android application for platform administrators and resellers.

## User access

- Admin: manages the platform, resellers and offers.
- Resellers: register, log in and manage their businesses.
- Customers: do not install or access this application.

Customers pay directly through M-Pesa to the advertised Buy Goods Till.
